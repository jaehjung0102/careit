## PR와 완료 기준

브랜치는 `feat/<담당>-<작업>`. PR에는 Issue 링크, 변경 경로, 데이터가 mock인지 실제 저장인지, 검사 결과, 검토할 화면을 적는다. F1↔F2, B1↔B2가 교차 리뷰한다. B1의 초대 수락 전에는 리뷰어 지정이 불가능하므로 댓글/할당표에 표시하고 수락 후 지정한다. `main`에는 정재헌이 최종 merge한다. Issue는 실제 완료 기준이 모두 검증된 후 닫는다.

현재 익명 사용자의 기록은 작성한 브라우저 계정에서만 조회된다. 팀 공동 조회/운영에는 인증과 소속·역할 정책이 필요하다. 실제 어르신 데이터를 입력하지 말고 개발용 가상 데이터만 사용한다.
